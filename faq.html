Butterfly Neural — FAQ & Troubleshooting

What do I need before I start?

A Shopify store with the Online Store channel, admin access, and (for filters) the free Search & Discovery app. No paid apps are required. Setup order that works: logo → menus → pages → metafields → filters → feature toggles. Full checklists are in PAGES-AND-METAFIELDS.md.

Which preset should I choose?

Butterfly Neural (dark flagship) or Light Minimal (white/blue). Both include every feature; they differ in palette and glow intensity. You can recolor either afterwards. Note: with a preset applied, compare and the bundle builder stay enabled and the FAB help button stays off — switch the Preset profile theme setting (preset_profile) to Manual if you want to override that per toggle.

Troubleshooting

My collection/search filters don’t filter (or a filter is missing)

Filters are managed in Shopify’s Search & Discovery app, not in the theme.

  1. Open Apps → Search & Discovery → Filters.
  2. Confirm the filter exists and is enabled (availability, price, vendor, tags, metafield filters…).
  3. Confirm your products actually carry the values (e.g., the tag or metafield) the filter uses.
  4. Reload the collection/search page. The theme renders whatever the app provides — there is no theme setting to fix here.

The compare bar/table is empty

That’s the expected empty state. Compare fills only when a shopper taps Compare on a product card (up to 3 products, stored in their browser). To test: open a collection, tap Compare on two products, then open the bar or visit your Compare page (template page.compare). If the buttons don’t appear at all: you’re on the Manual preset profile with Show product compare (enable_compare) off — turn it on (both presets keep compare on). Custom spec rows need the custom.compare_specs metafield filled in (see PAGES-AND-METAFIELDS.md).

The promo popup never shows

By design: the popup ships disabled (Footer group → Promo popup is disabled on a fresh install). Enable the section, write your copy, then check: Show on (all pages vs homepage), Delay before showing (default 8s), and the frequency cap — after a close or signup it stays hidden for the days you set (default 30) in that browser. Test in a private/incognito window.

Related articles is empty on a product

The section shows only articles linked to that product via the custom.related_articles metafield (Settings → Custom data → Products; type: Article, list of entries). Nothing linked = nothing rendered — that’s intentional. (Optional: enable Show latest posts when no articles are linked and pick a Fallback blog in the section settings.)

Where is search on mobile?

In the header: on screens ≤990px the desktop search bar hides and a search icon button appears next to the wishlist/cart icons. Tapping it opens the full search overlay with predictive suggestions. If suggestions don’t appear, check Theme settings → Search → Enable Autocomplete (enable_autocomplete) is on.

Light Minimal still looks dark / colors look wrong

  1. Confirm the Light Minimal preset is actually applied (Theme settings → preset picker) — or that Preset profile isn’t set to a dark manual palette.
  2. Hard-refresh (cached CSS can linger right after switching presets).
  3. Note: the header pill, search overlay, quick-view and card action buttons use intentional dark-glass styling in both presets (white icons/text over product imagery) — that part is by design, not a bug.
  4. Custom CSS/apps can override palette variables; disable them briefly to isolate.

The wishlist page is blank / the header heart goes nowhere

Create a page with template page.wishlist, then select it in Header → Wishlist Page. The wishlist itself is stored in the shopper’s browser — it will be empty on a new device/browser by design (no account sync).

The mobile bottom bar hides my footer

It shouldn’t: the bar is ~77px and the footer keeps clearance above it (compare bar also sits above it). If you added custom CSS with fixed elements, check their z-index/bottom offsets against --mobile-nav-height.

The kit cards / Categories sheet point to empty pages

  • Kits sheet cards link to /collections/starter-kits, /collections/pro-kits, /collections/enterprise-kits — create collections with those handles (or don’t enable the Kits tab).
  • The Categories sheet shows your Header Categories Menu; if empty it falls back to the mega-menu children, then the main menu. Build the menu under Content → Menus.

Track order doesn’t send shoppers anywhere

On the Track order page (template page.track-order), open the section and set: provider (AfterShip / Parcel Panel) with your branded tracking URL, or custom with your own tracking URL and the parameter names your provider expects (order_number, email, optional postal code).

My announcement marquee won’t scroll / slider won’t rotate

Announcement bar (Header group): Text display = Marquee for scrolling (adjust Scroll speed, Pause scrolling on hover) or Slider for rotation (Auto-rotate Announcements, Rotation Duration). Also check Show on Mobile if it vanishes on phones, and whether you closed it earlier in that browser session.

Can I move “Related articles”, “Compare”, etc. to a different spot?

Yes — product template sections are ordinary OS 2.0 sections; drag them in the theme editor. Sections can also be added to other templates where the editor allows; some (related articles, comparison) only make sense on product pages.

Does the theme work with Shopify apps?

Yes. App blocks are supported in product areas (main product and featured product include the @app block), and standard templates are included for cart, account, search, etc. If an app injects its own styles/scripts, conflicts are the app’s surface — test with the app disabled to isolate.

Will updating the theme erase my content?

Your products, pages, menus, and policies live in Shopify, not the theme — they’re safe. Theme-editor settings and template assignments can change when you publish a different theme, so duplicate your current theme before publishing an update and re-check the quick-start list.

How do I get help?

Support: https://butterfly-ai-studios.github.io/theme-support/ — include your store URL, theme version (1.0.26), preset, and screenshots. Support covers setup guidance and bugs in unmodified theme code.
