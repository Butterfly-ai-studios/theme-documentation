Butterfly Neural — Pages, Menus & Metafields Setup

Exact setup checklists. Everything here is done in Shopify admin / the theme editor; no code edits.

A) Pages to create

Create each page under Content → Pages, then set its Theme template (visible in the page editor’s right-hand panel). If the template dropdown is empty, publish/upload the theme first — templates ship with the theme.

# Page (suggested title) Theme template to assign What it powers Where to link it
1 Wishlist page.wishlist The wishlist page (browser-local saves) Header section → Wishlist Page (makes the header heart work)
2 Compare page.compare Full comparison table (up to 3 products) Add to a menu/footer if you want a standing link
3 Track order page.track-order Order-tracking form → your provider Mobile More sheet default; menus
4 Find a store page.find-a-store Store locator with search + distances Header utility bar / menus / More sheet
5 Bundle builder page.bundle 3-step build-a-bundle page Menus, homepage, product pages

Step-by-step (same for each page)

  1. Go to Content → Pages → Add page.
  2. Enter the title (e.g., “Wishlist”). The handle is created automatically (/pages/wishlist etc.).
  3. Set Visibility to Visible.
  4. In Theme template, choose the template from the table above.
  5. Save.
  6. Wire it up:
    • Wishlist: Customize → Header → Wishlist Page → select the page.
    • Track order: Customize → open the page → Track order section → choose provider (AfterShip / Parcel Panel / custom) and paste your branded tracking URL; set parameter names if your provider needs them.
    • Find a store: Customize → open the page → Store locator → add Store blocks (name, address, phone, email, hours, map URL, latitude/longitude, image, services).
    • Bundle builder: Customize → open the page → Bundle builder → add Base Product and Add-on Product blocks.
    • Compare: nothing to configure on the page itself; products arrive when shoppers tap Compare. Optionally add the page to a menu.

Template dropdown shows bare suffixes (“wishlist”, “compare”…) in some admin versions — selecting “wishlist” is page.wishlist. That’s expected.

B) Menus to create or check

Build menus under Content → Menus.

Menu Used by Notes
Main menu (handle main-menu) Header navigation, mega menu The header’s Menu setting defaults to main-menu. Give one item child links to power the mega menu (item handle default shop-by-categories, changeable in Header settings).
Categories menu (any menu you pick) Header search-bar “All Categories” dropdown + mobile Categories sheet Header → Categories Menu. If empty, the Categories sheet falls back to mega-menu children, then the main menu.
Footer: Quick links Footer column 1 Footer section → Links Menu (schema default points at the footer menu — repoint it to your own).
Footer: Support Footer column 2 Footer section → Support Menu.
Footer: Legal / Terms Footer Legal column Footer section → Legal Menu. Put your Privacy / Terms / Refund / Shipping pages here. (On mobile, policies also appear automatically in the More sheet — no menu needed for that.)
Mobile More menu (optional) Mobile bottom-nav “More” sheet Theme settings → Mobile navigation → Mobile More Menu (mobile_more_menu). If unset, the sheet uses built-in links (Track Order, Blog, Contact, FAQ, Find a Store, Account) from the page settings beside it: mobile_track_order_page, mobile_blog, mobile_contact_page, mobile_faq_page, mobile_store_page.
Customer account menu Account icon (new Shopify accounts) Theme setting customer_account_menu, default customer-account-main-menu.

Mobile kit cards also expect three collections to exist if you link them: starter-kits, pro-kits, enterprise-kits (titles/descriptions/images under Theme settings → Mobile navigation → Kit cards).

C) Metafields

Create under Settings → Custom data → Products (Add definition). Types must match exactly.

Namespace & key Type Used by What to enter
custom.related_articles Article — list of entries (list.article_reference) Product page → Related articles section Pick the blog articles related to that product. The section renders nothing until at least one article is linked.
custom.compare_specs List of metaobjects whose entries have label and value fields Compare bar/modal + Compare page spec rows One entry per spec, e.g., label “Battery”, value “20 hours”. Price, vendor, type and availability rows are automatic.
butterfly.use_case Single line text Smart recommendations (metafield_match, best_match) A short use-case slug you reuse across products, e.g. home, office, travel. Same use case = +3 points.
butterfly.skill_level Single line text Smart recommendations (metafield_match, best_match) e.g. beginner, intermediate, expert. Same level = +2 points.

Notes:

  • butterfly.use_case / butterfly.skill_level are optional. Without them, smart recommendations still work on shared tags (+1 per shared tag) with the tag_overlap or best_match strategy.
  • The kit-selector quiz and gadget finder do not need metafields: kit-selector results are the Recommendation blocks you author; gadget-finder answers map to ordinary product tags.
  • Metaobject for compare specs: if the “list of metaobjects” type is new to you — Settings → Custom data → Metaobjects → Add definition (fields label, value, both single-line text), then create the product metafield as a list referencing that metaobject type. The theme reads only label/value.

D) Shopify Search & Discovery (filters)

Collection and search filters are configured in Shopify’s app, not in the theme:

  1. Install/open Search & Discovery (Shopify admin → Apps).
  2. Go to Filters and add the filters you want (availability, price, vendor, product type, tags, or metafield-based filters).
  3. Optionally tune search settings and product boosts in the same app.
  4. The theme automatically renders your filters on collection pages and the search page, with sorting. No theme setting is needed.

If filters “don’t filter”, the cause is almost always app-side (filter not added, or products missing the tagged/metafield values) — see FAQ.md.

E) Quick wiring checklist

  1. Pages created + templates assigned (table A).
  2. Header Wishlist Page selected; Menu = your main menu.
  3. Footer menus repointed to your menus (not the schema defaults).
  4. Metafields created (table C); a few products filled in.
  5. Search & Discovery filters configured (section D).
  6. Policies written under Settings → Policies (they appear in the mobile More sheet and belong in your footer Legal menu).
  7. Promo popup left disabled until you actually want it (Footer group → Promo popup → enable).
