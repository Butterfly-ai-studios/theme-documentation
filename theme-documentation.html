Butterfly Neural — Buyer Documentation

Theme: Butterfly Neural
By: VOOQIO INC
Documentation version: 1.0.26
Online documentation: https://butterfly-ai-studios.github.io/theme-documentation/
Support: https://butterfly-ai-studios.github.io/theme-support/

Butterfly Neural is a premium Shopify Online Store 2.0 theme built for tech and gadget stores. It ships with two visual presets, a rich product-page toolkit (quick view, compare, wishlist, bundles, kit finder), and a native-app-style mobile navigation — all configurable from the theme editor, with no apps required for the core features.

This documentation describes exactly what the theme does and how to set it up. Every feature listed here exists in the theme code; where a feature needs your input (a menu, a page, a metafield, a phone number), the docs say so.

1) Requirements

  1. A Shopify plan with the Online Store channel enabled.
  2. Admin access to Online Store → Themes, Content, and Settings → Custom data (for metafields).
  3. For collection/search filters: the free Shopify Search & Discovery app (filters are managed there — see PAGES-AND-METAFIELDS.md).
  4. A modern browser for the theme editor (latest Chrome, Safari, Firefox, or Edge).

No paid apps are required.

2) The two presets

Apply a preset in Online Store → Themes → Customize → Theme settings → Colors (choose a preset from the preset picker), or start from a fresh install and pick one:

Preset Look Palette
Butterfly Neural (flagship) Dark, neon-accented, glass surfaces Deep background #0a0a0f, cyan #00ffff, magenta #c03bc4
Light Minimal Clean light storefront, blue accents White #ffffff background, blue #2563eb / sky #0ea5e9

Preset notes (important):

  • Both presets keep product compare and the bundle builder enabled, and keep the FAB help button off. If you switch the Preset profile theme setting (preset_profile) to Manual, your individual feature toggles apply instead — see Theme settings → “Preset features”.
  • You can recolor either preset freely afterwards; the preset is a starting point, not a lock-in.

3) Installation

  1. Go to Shopify Admin → Online Store → Themes.
  2. Click Add theme → Upload zip file and upload the theme package (Butterfly-Neural-v1.0.26.zip).
  3. Wait for processing, then click Customize on the uploaded theme.
  4. Work through the Quick-start checklist below.
  5. Click Publish only after your checks pass.

Tip: Always duplicate your current live theme before publishing a new one, so you can roll back.

4) Quick-start checklist

  1. Logo & favicon — Theme settings → Branding (favicon), and Header section → Logo Image. No logo? The header automatically shows the bundled butterfly mark with your shop name. Same in the footer.
  2. Menus — Content → Menus: build your main menu; the theme looks for the main-menu handle by default (Header → Menu). Create footer menus and the mobile “More” menu (optional). See PAGES-AND-METAFIELDS.md.
  3. Pages — Create Wishlist, Compare, Track order, Find a store, and Bundle pages and assign the matching theme templates (exact steps in PAGES-AND-METAFIELDS.md).
  4. Homepage — Customize → Home page: hero, kit cards, featured products, kit selector, testimonials, newsletter. Replace all placeholder copy with your own.
  5. Testimonials — The shipped testimonial text is clearly-labelled placeholder copy. Replace it with genuine customer feedback before launch (see the honest note in FEATURES.md).
  6. Metafields — Add custom.related_articles, custom.compare_specs, and (optionally) butterfly.use_case / butterfly.skill_level under Settings → Custom data (table in PAGES-AND-METAFIELDS.md).
  7. Filters — Install Shopify Search & Discovery and configure collection/search filters there; the theme displays them automatically.
  8. Feature toggles — Theme settings → “Preset features”: quick view, wishlist, compare, bundle builder, WhatsApp inquiry (needs your number), FAB help (off by default), back-to-top.
  9. Promo popup — It ships disabled. Enable it in the Footer group only when you want it; it is frequency-capped so it does not nag.
  10. Test — Add to cart, quick view, compare, wishlist, mobile bottom navigation, and checkout redirect on a real phone.

5) Support

  • Support page: https://butterfly-ai-studios.github.io/theme-support/
  • Scope: installation help, setup guidance, and bug reports for unmodified theme code.
  • Custom design/development work is not included in theme support.
  • When contacting support, include: your store URL, theme version (1.0.26), the preset you use, and screenshots of the issue.

6) Honest notes

  • No “AI-powered” anything. Recommendations, the kit selector, and the gadget finder use plain tag and metafield matching that you control. The theme makes no machine-learning claims.
  • No fake urgency. The deal countdown only ever shows an end date you set. The promo popup ships disabled and is frequency-capped.
  • Browser-local features. Wishlist, compare, and recently viewed are stored in the shopper’s browser (no account needed, no cross-device sync).
  • Performance. The theme avoids heavy libraries and loads feature scripts only where the feature appears. We do not promise specific speed scores — your images and apps affect results most.
