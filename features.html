Butterfly Neural — Feature Guide

Every merchant-facing feature in the theme, where it appears, and how to configure it. Global switches live in Customize → Theme settings; per-section options live in the theme editor when you select the section.

Preset behaviour: with the Butterfly Neural or Light Minimal preset applied (theme setting preset_profile), product compare and the bundle builder stay enabled and the FAB help button stays off. Set preset_profile to Manual if you want the individual toggles below to apply exactly as switched.

Header

Logo with shop-name fallback

Shows your uploaded logo, or — if none is uploaded — the bundled butterfly mark together with your shop name. The footer uses the same idea (your footer logo image wins; otherwise mark + shop name). Configure: Header section → Logo Image and Logo Width; Footer section → Show Footer Logo, Footer Logo Image, Footer Logo Width/Height. Nothing is hard-coded: names always come from your store.

Sticky header & utility bar

A sticky header with an optional utility bar at the very top: rotating announcements (add Utility announcement blocks), an optional Help Center link, an optional Find a Store link, and optional social icons. Configure: Header section → Sticky Header, Enable Utility Bar, Auto-Rotate Announcements, Announcement Rotation Interval, Help Center Page/URL, Find a Store Page/URL. Needs from you: a help/store page if you enable those links.

Mega menu & dropdowns

Desktop navigation with a wide mega-menu panel for one chosen menu item, optional highlighted item, an optional “premium” dropdown style, and hover promo panels with cards. Configure: Header section → Enable Mega Menu, Mega Menu Item Handle (default shop-by-categories), Mega Menu Columns, Mega Menu CTA Collection; blocks Menu tile, Promo panel, Mega feature; Highlight a Menu Item; Enable Promo Hover Panels. Needs from you: a menu (Header → Menu, default handle main-menu) with child links for the mega-menu item.

Search bar, search overlay & predictive suggestions

The desktop search bar opens a full search overlay. As the shopper types, predictive suggestions appear (products, with optional collection/page results), including recent searches. Product prices in suggestions are your real, current prices. Configure: Header section → Show Search Bar (Desktop), Categories Label, Categories Menu (the “All Categories” dropdown); Theme settings → Search: Enable Autocomplete (enable_autocomplete), Autocomplete Results Limit, Show Product Thumbnails, Show Collections & Pages (show_collections_pages, off by default), Show Recent Searches. Mobile: the header shows a search icon button on small screens (≤990px) that opens the same overlay — see Mobile bottom navigation.

Wishlist & cart icons, currency/language switchers

Header icons link to your wishlist page and open the cart drawer. Currency and language switchers use Shopify Markets localization forms (single-language stores show a plain label, not a dead dropdown). Configure: Header section → Wishlist Page (pick the page you created with the page.wishlist template), Show Currency Switcher, Show Language Switcher. Needs from you: the Wishlist page (see PAGES-AND-METAFIELDS.md); markets configured in Shopify Settings for switchers to list options.

Cart drawer with free-shipping progress

Slide-out cart with an optional free-shipping progress bar and an optional cross-sell row from a collection you pick. AJAX adds from quick add, bundles, and the sticky bar open the drawer instead of jumping to the cart page. Configure: Cart drawer section → Show free shipping bar (show_free_shipping_bar), Free shipping threshold (in shop currency), messages, Show cross-sell (show_cross_sell), Cross-sell collection/heading/limit.

Announcement bar

A top bar (in the Header group) with one or more announcements, each with icon, text, and link. Text display is your choice:

  • Slider (default): announcements rotate automatically (Auto-rotate Announcements, Rotation Duration default 5s).
  • Marquee: continuously scrolling text, with Scroll speed and Pause scrolling on hover.

It also supports an optional background image/GIF with a darkening overlay, a close button, mobile visibility toggle, auto-close timer, and close-on-scroll. Closing it collapses the bar completely (no leftover gap). Configure: Header group → Announcement bar section; add Announcement blocks. Preset running the demos: the slider (calmer); marquee is there when you want it.

Mobile bottom navigation

An app-style fixed bottom bar on mobile/tablet (rendered by the Header section), with tabs you can toggle: Home, Kits, Products, Categories, More. Labels can be shown or hidden; optional hide-on-scroll. At phone sizes the bar is ~77px tall with 56px tap targets.

Configure: Theme settings → Mobile navigation: Enable Mobile Bottom Navigation (enable_mobile_nav), Show Labels, Enable Kits/Products/Categories Tabs, Enable More Tab (Mobile) (enable_mobile_more_menu), More Tab Label, Hide on Scroll Down (enable_hide_on_scroll, off by default).

Sheets (bottom panels)

  • Kits sheet: three kit cards — Starter / Pro / Enterprise — each linking to /collections/starter-kits, /collections/pro-kits, /collections/enterprise-kits. Titles, descriptions, and images come from Theme settings → Mobile navigation → “Kit cards”. Create collections with those handles to use it.
  • Categories sheet: a browsable category grid from your categories menu (Header → Categories Menu), falling back to your mega-menu children, then the main menu. Title: Header → Categories Sheet Title.
  • More sheet: support/info links. If you assign a menu (Theme settings → Mobile More Menu, mobile_more_menu), its links are used; otherwise the sheet shows Track Order, Blog, Contact, optional FAQ, optional Find a Store, and Login / My Account. Page targets come from mobile_track_order_page, mobile_blog, mobile_contact_page, mobile_faq_page, mobile_store_page (sensible path defaults like /pages/track-order apply).
  • Automatic Legal links: below those links, the More sheet adds a Legal group built automatically from your Shopify policies (Settings → Policies): every policy you actually have (Privacy, Terms, Refund, Shipping…) appears with its real title and URL; nothing is hard-coded, and the group hides entirely if you have no policies.

Mobile header search

On phones, the desktop search bar hides and a search icon button appears in the header action row (next to wishlist/cart). It opens the same search overlay with predictive suggestions — so search is always one tap away on mobile.

Product cards

Used across collection grids, featured products, recommendations, search, and more.

  • Quick add — adds the first available variant via AJAX and opens the cart drawer; shows an “Added!” confirmation.
  • Quick view — opens a modal with gallery image, variant picker, quantity, add-to-cart, full-details link, and (if enabled) the WhatsApp inquiry link. Configure globally: Theme settings → Enable quick view (enable_quick_view).
  • Wishlist heart — saves the product in the shopper’s browser. Toggle: Enable wishlist (enable_wishlist).
  • Compare — adds the product to the compare tray (see Compare system). Toggle: Show product compare (enable_compare; always on under both presets — see the preset note at top).
  • Badges — Sale, Sold out, New/Best Seller/Limited (tag-driven), shown over the image; sold-out chips stay readable in both presets.

On touch devices there is no hover, so the card actions stay visible as a compact icon bar at the bottom of the product image (quick add / quick view / wishlist / compare), with text labels for assistive tech. On desktop they reveal on hover or keyboard focus.

Product page

Template sections, in order: breadcrumb, main product, complementary products, product recommendations, related articles, product comparison, recently viewed, sticky add-to-cart.

  • Main product — media gallery, variant picker, quantity, buy buttons (incl. dynamic checkout), selling plans, pickup availability, inventory status, description, app blocks, and merchant collapsible rows (add Collapsible row blocks for shipping/warranty/details) and Tech spec rows. Desktop sticky buy box is optional (Enable Sticky Buy Box (Desktop)).
  • WhatsApp inquiry — an “Ask on WhatsApp” button under the buy area (also offered inside quick view). Off by default. Enable it with your number: Theme settings → Enable WhatsApp product inquiry (enable_whatsapp_inquiry), WhatsApp number (whatsapp_phone_number, international format), WhatsApp button label. The button opens WhatsApp with a pre-filled question about that product. No number = no button.
  • Complementary products — “Pairs well with”, powered by Shopify’s Search & Discovery complementary recommendations. Heading/limit in the section settings.
  • Recommendations — Shopify’s product recommendations (“You may also like”), heading/limit configurable.
  • Related articles — shows blog articles you link to the product. See the metafield setup in PAGES-AND-METAFIELDS.md (custom.related_articles). Shows nothing when nothing is linked (an optional fallback to your latest blog posts exists, off by default: Show latest posts when no articles are linked + Fallback blog).
  • Recently viewed — browser-local rail of products the shopper viewed (excludes the product they’re on).
  • Sticky add-to-cart — a bar that appears after scrolling (Show after scrolling (px), default 600), with optional image and variant picker; adds via AJAX.

Compare system

Shoppers tap Compare on product cards to collect up to 3 products (stored in their browser). A compare bar lets them open the comparison; the product-comparison section (placed on collection and product templates) shows the bar/modal, and a dedicated Compare page renders the full table.

  • Table rows: price, vendor, type, availability — always — plus any spec rows from the product metafield custom.compare_specs (see PAGES-AND-METAFIELDS.md).
  • Configure: Theme settings → Show product compare (enable_compare); Product Comparison section → Max Products to Compare (default 3).
  • Needs from you: a page with template page.compare (steps in PAGES-AND-METAFIELDS.md). The header/menu link is yours to add.
  • Empty state is explained to the shopper; there is nothing to “fix” if it’s empty — they just haven’t added products yet.

Wishlist

Heart buttons on cards (and the header icon) save products to a wishlist stored in the shopper’s browser only — no account, no sync across devices, and the theme copy says exactly that. Needs from you: a page with template page.wishlist; pick it in Header → Wishlist Page so the header icon and empty-state links land there. Copy (heading, intro, empty text) is editable in the Wishlist section.

Smart recommendations (“You May Also Like”)

Rule-based recommendations you control — not machine learning, and never labelled “AI” in the theme.

How matching works (scored, highest first):

Strategy What it does
tag_overlap +1 for each product tag shared with the current product
metafield_match +3 for same butterfly.use_case, +2 for same butterfly.skill_level
best_match (default) Combines both scorings above

Configure: section settings → Base Source (current product / a collection / manual collection), Strategy, Products to Show, Fallback Collection (used when nothing matches), card options (badges, quick add, CTA text), optional “Best match” badge (show_ai_badge — off by default; it’s a plain “Best match” label, not an AI claim), and reason lines (e.g., “Perfect for your use case”). Needs from you (optional): the metafields butterfly.use_case and butterfly.skill_level on products for metafield matching; tags alone work too. Toggle globally: Show smart recommendations (enable_smart_recommendations; on under both presets).

Kit selector

A 4-step guided quiz (use case → budget → experience → result) built from blocks you author: Use case, Budget, and Experience option blocks, ending on Recommendation cards (product, title, description, three feature bullets) that you write and tag with the use-case/budget/experience values they suit. It ends on real, merchant-curated kits — there is no fake “analyzing” step. Configure: Kit selector section (on the homepage by default); global toggle Show kit selector (enable_kit_selector).

Bundle builder

A 3-step builder on a dedicated page: choose a base product, add optional accessories, review, and add the whole bundle to the cart in one click. Prices are the real product prices; the total updates live. There is no invented bundle discount — if you want bundle pricing, use Shopify discounts. Configure: page with template page.bundle; Bundle builder section → Base Product and Add-on Product blocks. Global toggle: Show bundle builder (enable_bundle_builder; on under both presets).

Gadget finder quiz

A 3-question helper (“What will you use it for?”, budget, priority — all editable). Each answer is mapped to a product tag; products in a collection you choose are ranked by how many chosen tags they carry, and the top matches render as cards. Plain tag matching — stated as such in the section’s own copy. If nothing matches every answer, shoppers see the closest picks with a note saying so. Configure: Gadget finder section → Recommendation pool collection, Products to show, question texts; Answer blocks (each: which question, label, tag).

Deal countdown

A sale section with a countdown to an end date you set — used for real sales only. After the date, it shows your “expired” message or hides itself, and it can show products from a deals collection plus a featured product. Configure: Deal countdown section → Sale end date/time (end_datetime, format YYYY-MM-DD HH:MM or ISO), Auto-hide when expired (hide_expired), Expired message, Deals collection, Featured product, quick-add toggle. The section’s own settings remind you: real, merchant-set sale end times only.

Promo popup

A newsletter/promo popup placed in the Footer group. It ships DISABLED by default — nothing pops up on a fresh install. To use it: enable the section in the Footer group and write your heading/text (optional image, email form, success message).

  • Show on all pages or homepage only (Show on), delay (default 8s), and a frequency cap: after a close or signup it stays hidden for the days you set (default 30) via browser storage.
  • Default copy is neutral (“Join our list”); any offer wording is yours to write. The popup adds no countdowns or discount promises by itself.

FAB help button (off by default)

An optional floating help button (bottom-right). It appears only when enabled and you’ve given it somewhere to go: Theme settings → Show FAB help (Shopify Inbox or fallback links) (enable_fab_help, off in both presets) plus a FAB help page (fab_help_page) or FAB help URL (fab_help_url). It links shoppers to that page/URL; it does not embed a chat widget by itself.

Footer

Merchandisable columns and trust elements:

  • Logo/shop-name fallback (same behaviour as the header), mission text, and social icons (Facebook, Instagram, TikTok, YouTube, X, Pinterest — from Theme settings → Social media; icons show only for URLs you enter).
  • Three menu columns — Quick links, Support, and a Legal / “Terms & Conditions” column — each bound to a menu you choose (Footer section → Links Menu, Support Menu, Legal Menu). Point the legal column at a menu containing your policy pages.
  • Newsletter block (heading/text editable) using Shopify’s customer signup form.
  • Trust badges (two text slots; first defaults to “Secure Checkout”) and optional accepted-payment icons (Show accepted payment icons).

Blog & article pages

Standard Shopify blog, themed end-to-end:

  • Blog page (main-blog): paginated article grid with images, dates/authors, excerpts. Articles per page configurable.
  • Article page (main-article): full article layout with comments support.

You post from Shopify admin → Content → Blog posts — no theme work needed. Link the blog wherever you like (main menu, footer menu, mobile More sheet Blog target). Products can surface related posts with the Related articles section above.

Track order page

A page where shoppers enter order details and are sent to your tracking provider. The form is a configurable GET form: choose a provider (AfterShip, Parcel Panel, or custom) or paste any tracking URL, and set the query parameter names (order number, email, optional postal code). Needs from you: a page with template page.track-order and your provider/branded tracking URL (main-track-order section settings).

Store locator (Find a store)

A store list with optional hero, text search, “near me” geolocation with distances (km/mi), service badges, opening hours, phone/email, map links, and store photos. Configure: page with template page.find-a-store, then Store blocks in the Store locator section (name, address, phone, email, hours, map URL, latitude/longitude, image, services). Link it from the header utility bar or menus.

Collections, search results & filters

  • Collection pages: filter panel + sortable product grid (24 per page pagination), wired to Shopify’s standard filters.
  • Search page: the same faceted filters and sorting on search results, with product/collection/page result types.
  • Filters come from the Shopify Search & Discovery app. The theme renders whatever filters you configure there (availability, price, vendor, tags, metafields…). If a filter seems missing, it’s an app-side setting — see FAQ.

Homepage & content sections

  • Butterfly Hero — headline, subtext, image, primary/secondary buttons, optional Trust signal blocks.
  • Butterfly Slideshow — image/video slides with autoplay, arrows, dots, focal points.
  • Butterfly Product Grid — a collection’s products with card actions; custom button text.
  • Featured collections / Featured product — collection cards; a single-product spotlight using the standard product blocks.
  • Specs sections — AI Tech Specs block list (butterfly-specs; add Spec blocks) and a scrolling specs layout (butterfly-specs-scrolly). Names aside, these simply present specs you write.
  • Newsletter section — standalone email signup for the homepage.
  • FAQ — FAQ item blocks (question + rich-text answer) under your heading.
  • Testimonials — Testimonial blocks (quote, author name/title, optional photo, optional star rating 0–5).

Honest-launch note (testimonials): the shipped testimonial text is placeholder copy (“Add a customer quote here — replace this placeholder with real feedback…”) with zero ratings. Replace every block with genuine customer feedback before you publish, or remove the section. Never present placeholder quotes as real reviews.

Back-to-top & small print

  • Back-to-top floating button (Theme settings → enable_back_to_top, on by default).
  • Contact page (main-contact) and standard 404, password, gift-card, cart, account templates are included and styled to match.
  • Customer accounts use Shopify’s native account components where applicable.
