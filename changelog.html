Butterfly Neural — Changelog

Versioning: the current package is 1.0.26. Earlier numbered builds (1.0.0–1.0.22) were development iterations of this same release; their work is summarized under 1.0.22 because the repo was not tagged per build. Summaries below reflect the actual git history — nothing here is aspirational.

1.0.26 — Related articles on product pages

  • New Related articles section on the product template (after product recommendations). It renders only articles the merchant linked to the product through the custom.related_articles metafield (list of article references); nothing is shown when nothing is linked. Optional fallback (default off) shows latest posts from a merchant-picked blog.
  • Localized “Read article” string in all 6 bundled locales (en, de, es, fr, ja, pt).
  • Theme Check: 104 files, 0 offenses.

1.0.25 — Legal links in the mobile More sheet + Light Minimal backdrop fix

  • The mobile More sheet gains an automatic Legal group built from shop.policies — real policy titles/URLs, hidden when a store has no policies. Localized “Legal” heading in all 6 locales.
  • Fix (Light Minimal): the flagship body rule in theme.css was never closed, so the body.theme-style-light override nested inside it and never matched — Light Minimal pages kept the dark flagship gradient over the white palette. The rule is now closed and the override applies. Verified in a 390×844 Light simulation built from the shipped files (white backdrop, navy titles, sky-blue prices).

1.0.24 — Mobile search + touch-visible card actions

  • Mobile header search: on ≤990px the desktop search bar hides; a search icon button (previously a CSS class with no element) now sits in the header action row and opens the search overlay. All [data-search-toggle] elements are bound, with aria-expanded kept in sync.
  • Product-card actions on touch: Quick Add / Quick View / Wishlist / Compare were hover-only (unreachable on phones). On (hover: none) they render as an always-visible compact icon bar (44px tall, labels kept for assistive tech), plus a :focus-within reveal for keyboard users. Applied in both theme.css and the collection grid’s card CSS.
  • Verified in a 390×844 touch simulation from the real files: search overlay opens/focuses/closes; Quick View loads; Quick Add posts to cart; Compare toggles, bar and storage all pass.

1.0.23 — Neutral merchant defaults (naming cleanup)

  • Shipped defaults no longer carry demo/AI-gadget copy: hero/slideshow headings default to “Butterfly Neural”, “New to AI gadgets” → “New to gadgets”, mega-menu default text neutralized; matching preset content in templates/index.json, index.minimal.json, page.demo-minimal.json (and the /listings mirrors). The theme name is Butterfly Neural everywhere; demo store names are store settings, not theme content.

1.0.22 and earlier — how this release was built (summary of git history)

  • Mobile bottom navigation: distinct Kits (package) icon vs Products (bag) icon; aria-controls/aria-expanded wiring on Kits/Categories/More sheets, synced in mobile-nav.js and the header fallback handler.
  • Footer/header logos follow the merchant: a merchant-uploaded logo wins; otherwise the bundled butterfly mark plus the live shop name (preset-aware gradient). No hard-coded store names in shipped files; theme_author is VOOQIO INC.
  • Announcement bar: optional scrolling (marquee) text with direction/speed/pause-on-hover over image/GIF backgrounds; fully collapses on close (no leftover gap); text follows the preset palette.
  • Light Minimal correctness: the whole palette (incl. glows, glass, premium surfaces) is emitted from effective preset vars in theme.liquid; footer text, card actions (dark-glass pills with white text in both presets), switchers, cart drawer, filters panel, and compare bar/modal all follow the preset. Sold-out badges are dark chips in both presets.
  • Cart: free-shipping progress + cross-sell row in the drawer; AJAX adds open the drawer instead of navigating to /cart; sticky ATC adds via AJAX.
  • Compare: one localStorage record set, client-side compare page (page.compare), honest price filter, compare CTA ink matches quick-add; max 3 products.
  • Search: predictive-search autocomplete fixed (real prices, locale currency), soft focus ring on the search pill.
  • Wishlist (browser-local, account-free), WhatsApp product inquiry (optional merchant number, off by default), promo popup ships disabled and frequency-capped, kit selector with real (merchant-authored) recommendations, gadget finder tag matching, deal countdown with merchant-set dates only.
  • Honesty pass: invented named testimonials replaced with clearly-labelled placeholders (no ratings, no claims); free-shipping/AI badge defaults neutralized; bundle builder phantom discount removed; “Smart recommendations” documented as tag/metafield matching.
  • Store locator upgraded (search, near-me distance, service badges); language/currency switchers wire every instance; collection grid paginates instead of silently truncating at 50 products; header nav defaults to the standard main-menu handle.

Notes

  • Shopify’s ZIP importer once silently dropped 6 files because of blank schema "default": "" values (fixed in commit ef7fbca). If you ever upload by ZIP and a section seems missing, re-upload the current package or contact support.
  • The bundled footer trusts copy, hero copy and testimonial text are starter placeholders — write your own before launch.
